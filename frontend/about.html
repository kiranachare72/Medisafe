Research Project Information

MediSafe: Integrated Patient Care & Medication System

MediSafe is a real-world, full-stack healthcare web application engineered for a final-year BSc Information Technology research project. It solves critical gaps in patient adherence, medical document centralization, and caregiver coordination.

Architecture & Technology Stack

  • Frontend: Pure HTML5, CSS3, Vanilla JavaScript (ES6+), Fetch API. Responsive for desktop, tablet, and mobile browsers.
  • Backend: Python 3.x, Django 6.x, Django REST Framework.
  • Database: MongoDB Atlas Cloud NoSQL database, interfaced via pymongo for native document persistence.
  • Authentication: bcrypt one-way salted hashing, PyJWT stateless token authorization with per-request verification.
  • OCR Engine: Tesseract OCR with PIL/Pillow preprocessing for optical text recognition from prescription images.
  • Emergency Geolocation: HTML5 Geolocation API with real-time coordinate translation to Google Maps links.

Key Research Objectives

1. Medication Adherence

Mitigating missed dosage incidents through active scheduling and historical log verification.

2. Document Integrity

Encrypted, owner-verified medical records storage avoiding file exposure.

3. Caregiver Access Control

Granular token-based permissions for family members and caretakers.
